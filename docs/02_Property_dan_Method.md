# 02. Property dan Method pada C++

Materi ini membahas Komponen Internal Class yang bersumber dari Video #2 dengan durasi 30:22.

## Pemahaman Dasar
* **Apa itu?** Property adalah variabel penampung data milik class (member variable)[cite: 1]. Method adalah fungsi di dalam class yang menentukan perilaku objek (member function)[cite: 1].
* **Mengapa digunakan?** Konsep ini digunakan untuk menggabungkan keadaan (state) dan perilaku (behavior) entitas dalam satu wadah[cite: 1].
* **Masalah apa yang diselesaikan?** Hal ini mencegah variabel terpisah kehilangan relevansi fungsi pemrosesnya[cite: 1].
* **Bagaimana cara kerjanya?** Property menyimpan nilai objek, sedangkan Method beroperasi menggunakan data dari property tersebut[cite: 1].
* **Kapan digunakan?** Konsep ini digunakan pada setiap Class yang membutuhkan atribut data dan aksi[cite: 1].

## Konsep Inti & Ringkasan Cepat
* **Inti Konsep:** Property berfungsi untuk menyimpan data atau state, sedangkan Method menentukan aksi atau behavior[cite: 1].
* **Mengapa Penting:** Konsep ini membuat objek menjadi aktif dan dapat memproses datanya sendiri[cite: 1].
* **Kesalahan Umum:** Kesalahan pemula yang sering terjadi adalah lupa memberikan titik koma `;` di akhir definisi class atau salah memanggil method tanpa menggunakan tanda kurung `()`[cite: 1].
