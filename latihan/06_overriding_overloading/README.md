# Latihan Modul 6: Overriding & Overloading

**Deskripsi Soal:**
* Demonstrasikan dua konsep polymorphism[cite: 2]:
    1. **Method Overloading**: buat class `Kalkulator` dengan dua method `tambah(int, int)` dan `tambah(double, double)`[cite: 2].
