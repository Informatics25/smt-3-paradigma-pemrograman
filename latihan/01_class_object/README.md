# Latihan Modul 1: Class & Object

**Deskripsi Soal:**
* Buatlah sebuah class C++ bernama `Mobil` yang memiliki dua property publik: `merk` (string) dan `tahun` (integer)[cite: 2].
* Di dalam fungsi `main()`, instansiasikan dua buah objek mobil (misalnya `mobil1` dan `mobil2`), isi nilai property masing-masing objek, lalu cetak informasi kedua mobil tersebut ke layar[cite: 2].

**Kriteria Output:**
* Program harus menampilkan spesifikasi merk dan tahun pembuatan dari masing-masing objek yang dibuat[cite: 2].
