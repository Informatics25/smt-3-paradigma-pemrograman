# 🚀 Modul Pembelajaran Terintegrasi: Object Oriented Programming C++

Selamat datang di repositori pembelajaran **Object Oriented Programming (OOP) C++** untuk angkatan Informatika! 

Repositori ini merupakan rangkuman terstruktur dan sistematis dari seluruh materi playlist PBO C++ oleh channel **SWS Space (Study With Student)**. Modul ini disusun sebagai materi pembelajaran mandiri yang utuh agar kita dapat menguasai seluruh konsep tanpa perlu menonton ulang seluruh video.

---

## 🎯 Gambaran Umum & Peta Kurikulum
* **Cakupan Seri:** Terdiri dari 9 modul yang membahas fondasi PBO hingga implementasi program nyata.
* **Tujuan Pembelajaran Utama:** Memahami konsep dasar hingga arsitektur berorientasi objek serta mampu mengimplementasikannya secara tepat dalam bahasa C++.
* **Sasaran Pemelajar:** Mahasiswa, pemula, maupun pengembang perangkat lunak yang telah memahami dasar sintaks C++ dan ingin menguasai paradigma PBO.
* **Kompetensi Akhir:** Mampu merancang class, menerapkan enkapsulasi, pewarisan, polimorfisme, dan abstraksi untuk membangun aplikasi C++ yang rapi dan modular.

---

## 📂 Struktur Repositori

Repositori ini dibagi menjadi 3 bagian utama agar mudah dipelajari secara bertahap:

```text
oop-cpp-module/
├── docs/       # 📖 Berisi penjabaran teori (.md) dan matriks konsep (cheat sheet)
├── src/        # 💻 Berisi contoh implementasi kode C++ dari materi yang dibahas
└── latihan/    # 📝 Berisi soal praktik coding mandiri beserta kunci jawabannya
```

**Daftar Modul / Sesi:**
1. Class & Object
2. Property & Method
3. Constructor & Destructor
4. Setter & Getter
5. Inheritance (Pewarisan)
6. Overriding & Overloading
7. Access Modifiers (Encapsulation)
8. Class Abstract (Abstraksi)
9. Studi Kasus Mini Proyek Penjualan

## 🛠️ Cara Menggunakan Repositori Ini

1. **Clone Repositori**
   ```bash
   git clone https://github.com/USERNAME_ANDA/NAMA_REPO_ANDA.git
   cd NAMA_REPO_ANDA
   ```
2. **Pelajari Teorinya (Folder `docs/`)**
   Bacalah rangkuman materi dari modul 01 hingga 09. Jangan lupa cek `docs/00_Matriks_Konsep.md` jika Anda bingung membedakan istilah-istilah PBO.
3. **Eksplorasi Kode (Folder `src/`)**
   Buka folder `src/` untuk melihat kode C++ dari teori yang dibahas. Anda bisa menggunakan IDE seperti **CLion**, **Visual Studio Code**, atau **Code::Blocks**. Setiap folder sudah dilengkapi dengan file `CMakeLists.txt` untuk kemudahan proses *build* / kompilasi.
4. **Uji Pemahaman (Folder `latihan/`)**
   Kerjakan tantangan yang ada di file `README.md` dalam masing-masing sub-folder `latihan/`. Anda bisa mencocokkan hasil kodingan Anda dengan kunci jawaban yang tersedia di file `main.cpp`.
